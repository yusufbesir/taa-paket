# CI iş akışı (henüz etkin değil)

 dosyası GitHub Actions iş akışıdır. Bu makinedeki gh belirtecinde `workflow` kapsamı olmadığı için `.github/workflows/` altına gönderilemedi; Yusuf GitHub arayüzünden dosyayı `.github/workflows/ci.yml` olarak ekleyebilir ya da `gh auth refresh -s workflow` ile kapsam verilebilir.
